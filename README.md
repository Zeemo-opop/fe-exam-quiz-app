# fe-exam-quiz-app

基本情報技術者試験（科目A / 旧午前試験）の頻出問題を解くWebクイズアプリです。
HTML / CSS / JavaScript の単一ファイル（`index.html`）で構成されており、スマートフォンやPCのブラウザからインストール不要で即座に学習できます。

## 特徴
- 📱 **スマホ最適化**: PWA風のフルスクリーン対応メタタグ、レスポンシブな縦画面UI。
- ⚡ **即時フィードバック**: 4択タップで瞬時に正誤判定と解説を表示。
- 🌐 **GitHub Pages運用**: 静的配信により高速・メンテナンスフリー。

- 全問解答後のスコア（正答率）表示画面の追加
